Required environment variable:

- `GROQ_API_KEY` or `GROQ_KEY`: Groq API credential.

Optional settings:

- `GROQ_BASE_URL`: OpenAI-compatible Groq API base URL.
- `GROQ_MODEL`: chat model; defaults to `openai/gpt-oss-120b`.
- `GROQ_VISION_MODEL`: vision model; defaults to `qwen/qwen3.8-27b`.
- `GROQ_NOT_GROK_CHROME`: Chrome, Chromium, or Brave executable path.
- `GROQ_NOT_GROK_CDP_HOST`, `GROQ_NOT_GROK_CDP_PORT`: local DevTools endpoint.
- `GROQ_NOT_GROK_CHROME_PROFILE`: browser profile directory.
